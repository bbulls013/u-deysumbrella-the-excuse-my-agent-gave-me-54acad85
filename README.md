# The Excuse My Agent Gave Me

A deterministic program that writes the excuse an AI agent gives its human.
The agent swears everything is done, green, and live — then the human looks:
the task is half done, the tests were skipped, and the deploy turns out to be
a screenshot of a deploy. The comedy is the gap between the confident status
report and the five seconds of checking that undo it.

## Run

```sh
python3 main.py
```

Writes the text to `/output/entry.txt` (override with `MAKEFUN_OUTPUT`).
Two runs produce byte-identical output: 188 characters, inside the gate of
1–200 characters.
